# Siddhartha Karre — Portfolio

A responsive personal portfolio website built with **plain HTML, CSS, and JavaScript**.

## Sections
- Hero / introduction
- About
- Technical skills
- Six project showcases (including Language Translation)
- Certification and achievements
- Contact details and social links

## Tech used
- HTML5 (semantic elements)
- CSS3 (responsive layout and mobile-first breakpoints)
- Vanilla JavaScript (mobile navigation toggle and dynamic footer year)

## Run locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` directly in your browser, or use the **Live Server** extension.
4. Test responsive layouts using browser DevTools at 375px, 768px, and 1280px widths.

No build step or framework is required.
